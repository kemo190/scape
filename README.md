# مشروع سكيب (Scape) للإستشارات الهندسية - V2

هذا الملف يمثل ملخصاً شاملاً للمشروع لتوثيق حالة العمل الحالية، ليكون مرجعاً لأي مطور يكمل العمل على المشروع مستقبلاً.

## نظرة عامة على المشروع
المشروع عبارة عن موقع إلكتروني تعريفي لشركة **سكيب للإستشارات الهندسية** (شركة سعودية متخصصة في الاستشارات الهندسية، التصاميم المعمارية والإنشائية، ومخططات السلامة). 
تم تصميم الموقع بواجهة حديثة تعتمد على الرسوميات المعمارية (Blueprints) والتأثيرات الحركية المتقدمة.

## التقنيات المستخدمة
- **HTML5**: لبناء هيكل الصفحات والتنقل.
- **CSS3 (Vanilla)**: لتنسيق الموقع بشكل مجزأ (Modular) لسهولة الصيانة.
- **JavaScript (ES6)**: لإدارة التفاعلات الأساسية.
- **GSAP & ScrollTrigger**: مكتبة الحركات المتقدمة لعمل تأثيرات الـ Parallax وتمرير الصفحة (Scroll Animations).

## هيكل المجلدات والملفات (Directory Structure)
- `index.html`: الصفحة الرئيسية للموقع، وتحتوي حتى الآن على:
  - شريط التنقل (Navbar).
  - قسم البداية (Hero Section).
  - قسم "من نحن" (About Section).
- `css/`: يحتوي على ملفات التنسيق المجزأة:
  - `global.css`: التنسيقات العامة والمتغيرات.
  - `navbar.css`: تنسيقات شريط التنقل.
  - `hero.css`: تنسيقات قسم البداية.
  - `about.css`: تنسيقات قسم "من نحن".
  - `sections.css`: تنسيقات الأقسام المشتركة.
  - `responsive.css`: لتوافق الموقع مع الشاشات المختلفة.
- `js/`:
  - `main.js`: لإدارة التفاعلات الأساسية (مثل تغيير حالة الـ Navbar عند التمرير).
  - `animations.js`: يحتوي على فئة `AnimationController` التي تدير حركات GSAP (تأثيرات البداية، Parallax للصور، وحركات الـ Blueprint في قسم من نحن).
- `assets/`: يحتوي على الصور المستخدمة (Hero & About).

## ما تم إنجازه حتى الآن (Progress)
1. **شريط التنقل (Navbar):**
   - تم بناء الهيكل الأساسي وإضافة تأثير التمرير (Scrolled State).
   - يوجد زر قائمة للموبايل (Menu Toggle) يحتاج إلى استكمال برمجة القائمة الجانبية المنسدلة (Overlay).

2. **قسم البداية (Hero Section):**
   - إضافة صورة الخلفية مع تأثير Parallax عند تمرير الماوس وتمرير الصفحة.
   - حركات متتالية (Timeline) للنصوص والعناصر عند تحميل الصفحة باستخدام GSAP.
   - شبكة معمارية كخلفية (Architectural Grid Overlay).

3. **قسم "من نحن" (About Section):**
   - استخدام تأثيرات متقدمة (Blueprint to Reality Reveal) بحيث تظهر الخطوط الهندسية أولاً ثم تظهر الصورة الحقيقية مع النصوص باستخدام GSAP ScrollTrigger الذي يثبت القسم (Pin) حتى انتهاء الحركة.
   - استعراض خدمات الشركة (إستشارات هندسية، تصاميم، خدمات بيئية، إلخ) بشكل متتابع.

## الخطوات القادمة (To-Do / Next Steps)
- إكمال برمجة وعرض قائمة الموبايل (Mobile Menu Overlay) في `main.js`.
- بناء وتنسيق الأقسام المتبقية في `index.html` (مثل: خدماتنا، معرض الأعمال، المشاريع، فريق العمل، تواصل معنا) وإنشاء ملفات CSS الخاصة بها.
- ربط الأقسام الجديدة بنظام الحركات في `animations.js` (GSAP ScrollTrigger).
- تحسين التوافقية (Responsive Design) بشكل نهائي للأقسام الجديدة.

---
**ملاحظة للمطور المستقبلي:**
تم استخدام GSAP بشكل مكثف في `animations.js`. يرجى قراءة تسلسل الـ Timelines في `initHeroAnimations` و `initAboutAnimations` لفهم كيف يتم الكشف عن العناصر قبل إضافة أي حركات جديدة للأقسام المستقبلية.

## التشغيل والتطوير المحلي (Local Development)
نظراً لأن الموقع مهيأ للعمل على استضافة **Vercel** بمسارات مطلقة (Absolute Paths) وروابط نظيفة بدون `.html`، فإن تشغيله بالطرق التقليدية (مثل إضافة Live Server في VS Code) قد يؤدي إلى أخطاء 404.
لتشغيل الموقع محلياً بشكل صحيح وتطويره:
1. افتح التيرمنال داخل مجلد `scape-v2`.
2. قم بتشغيل السيرفر المحلي المخصص بكتابة الأمر التالي:
   ```bash
   python dev_server.py
   ```
3. افتح الرابط `http://localhost:8000` في متصفحك. هذا السيرفر يحاكي بيئة Vercel تماماً.
